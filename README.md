# AmazonHelp Twitter Support Agent — Hiver Take-Home

An AI support agent for **@AmazonHelp** (chosen brand) that, per message:
1. classifies intent into a 10-class taxonomy defined from the data,
2. drafts a reply grounded in retrieved historically-resolved threads,
3. decides `AUTO_HANDLE` vs `ESCALATE` with a stated reason.

**Read `report/REPORT.md` first** — problem framing, baselines, failure
analysis, and the mandatory "what's misleading about my headline number"
section live there. This README is just reproduction steps.

## ⚠️ About the data in this repo

This sandbox has no internet access, so the real ~3M-row Kaggle
`thoughtvector/customer-support-on-twitter` dataset could not be downloaded
here. `data/raw_synthetic_twcs.csv` is a **synthetic stand-in with the
identical schema** (`tweet_id, author_id, inbound, created_at, text,
response_tweet_id, in_response_to_tweet_id`), generated by
`src/generate_sample_data.py`, so the full pipeline is runnable end-to-end.
`eval/golden_set.csv` is likewise **synthetically labeled**, not hand-labeled
from real tweets — see the docstring in `eval/build_golden_set.py` for the
sampling/labeling protocol to actually use on the real data.

**To run on the real dataset:** download the Kaggle CSV to
`data/raw/twcs.csv`, then everywhere below replace
`data/raw_synthetic_twcs.csv` with `data/raw/twcs.csv`. No other code changes
are needed — `data_prep.py` works on either file since the schema is
identical. You'd then also need to genuinely hand-label a fresh
`eval/golden_set.csv` (protocol in `eval/build_golden_set.py`'s docstring) —
that labeling work can't be faked or skipped for a legitimate submission.

## Setup (< 15 minutes)

```bash
pip install -r requirements.txt

# Optional but recommended: enables the real LLM classifier/generator/judge
# instead of the keyword/TF-IDF/heuristic fallbacks. Everything below runs
# without this too — it just uses cheaper fallbacks and the report shows
# both numbers.
export ANTHROPIC_API_KEY=sk-...
```

## Reproduce headline results

```bash
# 1. Generate synthetic sample data (schema-identical to the real Kaggle CSV)
python src/generate_sample_data.py

# 2. Filter to the brand + reconstruct (customer -> brand reply) threads
python src/data_prep.py --raw data/raw_synthetic_twcs.csv --brand AmazonHelp \
    --out data/brand_threads.csv

# 3. Build the golden eval set (synthetic placeholder — see warning above)
python eval/build_golden_set.py
python eval/build_human_calibration.py

# 4. Run the full evaluation harness: intent metrics vs. 2 baselines,
#    escalation precision/recall, LLM-judge reply quality, judge-human
#    agreement. Prints + writes eval/eval_results.json
python eval/run_eval.py

# 5. Try the agent on a single message
python src/pipeline.py --message "Hi where is my order? day 5 and nothing here"
python src/pipeline.py --message "you charged my card twice, calling my lawyer"
python src/pipeline.py --message "still no refund, ridiculous" --no-llm   # forces TF-IDF baseline path
```

## Repo layout

```
src/
  generate_sample_data.py   synthetic Kaggle-schema data (sandbox stand-in only)
  data_prep.py               brand filter + thread reconstruction
  intents.py                 taxonomy + TrivialBaseline / TfidfBaseline / LlmIntentClassifier
  retrieval.py                TF-IDF retrieval over historical resolved threads
  reply_gen.py                grounded reply drafting (LLM or retrieval fallback)
  escalation.py                rule-based AUTO_HANDLE / ESCALATE decision + reasons
  pipeline.py                  orchestrates all of the above, CLI entrypoint
eval/
  build_golden_set.py          builds eval/golden_set.csv (+ sampling/labeling protocol)
  build_human_calibration.py   placeholder human-agreement calibration set
  llm_judge.py                  4-dim LLM-as-judge rubric for reply quality
  run_eval.py                   full harness: baselines, escalation P/R, judge, agreement
report/
  REPORT.md                     problem framing, results, failure analysis, next steps
decision_log.md                 non-obvious decisions and why
```

## What's borrowed vs. original

- Dataset schema and brand choice: Kaggle `thoughtvector/customer-support-on-twitter`
  (not downloaded here, see warning above).
- Libraries: `scikit-learn` (TF-IDF + LogisticRegression baseline, cosine
  similarity retrieval), `anthropic` Python SDK for LLM calls.
- All classification/retrieval/escalation/eval logic is original for this
  assignment, written against the public library APIs above.
